# Schriften für die Zahlen

Wählbar unter *Darstellung → Zahlen*. Die Schriften werden nur für Ziffern verwendet
(`unicode-range` in `index.html`) und liegen hier, weil die App wegen der
Content-Security-Policy und für den Offline-Betrieb keine fremden Server lädt.

Alle Dateien sind unverändert aus den angegebenen Paketen übernommen und stehen unter der
SIL Open Font License 1.1 (Lizenztexte daneben). Die Bezeichnungen „Kreide“, „Digital“ usw.
sind nur Namen in der App; die Schriften selbst behalten ihre Namen.
